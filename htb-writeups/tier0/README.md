# HTB Starting Point — Meow

- Enumeration is the process of collecting detailed information about a target system.

- It is performed after the scanning phase to gather in-depth details about the target.

- The main objective of enumeration is to identify users, services, shared resources, directories, operating systems, and software versions.

- It helps security professionals understand the configuration and structure of a system.

- Enumeration provides valuable information that can be used to assess the security posture of a network.

- It is considered one of the most critical phases of ethical hacking and penetration testing.

- Proper enumeration helps in identifying potential vulnerabilities and security weaknesses.

- Common tools used for enumeration include Nmap, Gobuster, Enum4linux, SMBClient, and Burp Suite.
